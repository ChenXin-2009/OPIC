# references — 外部资料存档

> 存放从互联网下载的研究材料、参考项目的源码快照/笔记、以及第三方文档摘录。

## 用途

- **已下载的网页/PDF** — 离线可查阅天文学论文、API 文档、算法说明
- **参考项目分析** — 同类开源项目的架构笔记、代码片段、设计决策记录
- **数据来源说明** — 星表、历表、TLE 等数据源的原始出处与获取方式
- **可复用资源** — 纹理、着色器、配置片段等可以直接引用到项目中的素材

## 约定

1. 每个资源单独一个子目录或文件，命名体现来源和主题
2. 文件首部包含元信息：来源 URL、下载日期、适用许可证
3. 不提交受版权保护的完整作品，仅存档摘要、笔记或合理引用片段
