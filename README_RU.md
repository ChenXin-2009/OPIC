## Введение в проект

OPIC — это интерактивное приложение для визуализации вселенной, созданное с использованием Three.js, Cesium и Next.js. Благодаря реальным астрономическим данным и точным орбитальным расчетам оно представляет динамическую симуляцию от поверхности Земли до края наблюдаемой вселенной.

Проект развивается в направлении модульной архитектуры плагинов (MOD Manager), которая позволяет загружать, настраивать и переключать функции независимо во время выполнения, без перезапуска приложения.

## Основные функции

### Визуализация Земли (интеграция с Cesium)

- Высокоточная тайловая Земля: глобальный рендеринг рельефа и изображений на основе Cesium
- Переключение карт из нескольких источников: поддержка Bing Maps, OpenStreetMap, ArcGIS, Tianditu и других источников изображений
- Реальные данные о высоте земного рельефа
- Адаптация по расстоянию: тайлы Cesium на близком расстоянии, переключение на сферу Three.js на дальнем расстоянии, плавный переход
- Синхронизация состояния камеры между Three.js и Cesium в реальном времени

### Симуляция Солнечной системы

- Высокоточная система эфемерид: на основе данных эфемерид NASA JPL DE440
- 27 небесных тел: точный расчет положений 8 основных планет + 19 основных спутников
- Управление временем: высокоточный временной диапазон 2009-2109, поддержка ускорения и замедления
- Динамический источник данных: автоматическое переключение между высокоточными эфемеридами ↔ аналитической моделью

### Отслеживание искусственных спутников

- Отслеживание в реальном времени: на основе данных TLE от CelesTrak и орбитальной модели SGP4
- Поиск спутников: просмотр и поиск искусственных спутников на орбите
- Визуализация орбит: отображение орбитальных траекторий и движения спутников
- Подробная информация: просмотр параметров спутников, орбитальных элементов и состояния

|---------|---------------------|-----------------|

| Солнечная система | 0,1 - 100 а.е. | NASA JPL DE440 |
| Близкие звезды | 0 - 100 световых лет | ESA Gaia DR3 |

| Наблюдаемая вселенная | 500M+ световых лет | Структура космической сети |

### Система MOD Manager (в разработке)

Модульная архитектура плагинов, которая поддерживает легкость основной системы, позволяя динамически загружать дополнительные функции во время выполнения:

- Декларативный манифест MOD с поддержкой семантического версионирования
- Полное управление жизненным циклом: registered → loaded → enabled → disabled → unloaded
- Автоматическое разрешение зависимостей с обнаружением циклических зависимостей
- Версионированный API-слой: Time, Camera, Celestial, Satellite, Render API
- Изоляция ошибок: сбои MOD не влияют на основную систему
- Сохранение конфигурации между сеансами

### Визуальные особенности

- Высококачественные текстуры планет (Solar System Scope)
- Рендеринг звезд на основе данных ESA Gaia
- Интерактивная камера: свободное вращение, масштабирование и фокусировка на небесных телах
- Бесшовные визуальные переходы между масштабами
- 4 уровня детализации, динамическая настройка по расстоянию

## Быстрый старт

### Требования к окружению

- Node.js 20+
- npm или yarn

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/ChenXin-2009/OPIC.git
cd OPIC

# Установить зависимости
npm install

# Запустить сервер разработки
npm run dev
```

Посетите `http://localhost:3000`, чтобы просмотреть приложение.

### Сборка продакшн-версии

```bash
npm run build
npm start
```

## Источники данных

### Данные эфемерид

| Небесное тело | Источник данных | Временной диапазон | Точность |
|---------------|-----------------|-------------------|----------|
| Земля, Марс, Луна | NASA JPL DE440 | 2009-2109 | <0,1° |
| Другие планеты | NASA JPL DE440 | 2009-2039 | <0,1° |
| Спутники Юпитера | NASA JPL JUP365 | 2009-2039 | <0,01° |
| Спутники Сатурна | NASA JPL SAT441 | 2009-2039 | <0,01° |
| Спутники Нептуна | NASA JPL NEP097 | 2009-2039 | <0,01° |

### Данные о вселенной

- Данные о звездах: ESA Gaia Mission (DR3)
- Местная группа: McConnachie (2012) Local Group Catalog
- Близкие группы галактик: Karachentsev et al. (2013)
- Сверхскопление Девы: 2MRS Survey Data
- Сверхскопление Ланиакея: Cosmicflows-3 Dataset

### Данные о спутниках

- Орбитальные данные TLE: CelesTrak (NORAD)
- Метаданные спутников: UCS (Union of Concerned Scientists) База данных спутников

### Визуальные ресурсы

- Текстуры планет: Solar System Scope
- Изображения Млечного Пути: ESA/Gaia

## Оптимизация производительности

- 4 уровня детализации, динамическая настройка по расстоянию
- Загрузка тайлов Земли по требованию, автоматическое удаление дальних тайлов
- Тайлы Cesium на близком расстоянии, сфера Three.js на дальнем расстоянии
- Пользовательская система частиц с шейдерами, поддержка миллионов частиц
- Инстансированный рендеринг для уменьшения вызовов отрисовки
- Отсечение по frustum, рендеринг только видимых объектов
- Автоматическое освобождение дальних ресурсов
- Web Workers для неблокирующей обработки данных

## Отказ от ответственности

Это приложение предназначено только для образовательных и развлекательных целей.

**Примечание о точности астрономических данных:**

В высокоточном временном диапазоне (2009-2109 для Земли/Марса/Луны, 2009-2039 для других небесных тел) используются данные эфемерид NASA JPL с точностью до угловых секунд. За пределами этого диапазона система автоматически переключается на аналитические модели с пониженной точностью.

Для точных астрономических данных для научных исследований или навигации обращайтесь к системе NASA JPL HORIZONS или другим официальным профессиональным астрономическим учреждениям.

**Примечание об орбитальных данных спутников:**

Орбитальные данные искусственных спутников основаны на TLE (Two-Line Element) и модели SGP4, точность которых зависит от таких факторов, как атмосферное сопротивление и давление солнечного излучения, только для справки.
