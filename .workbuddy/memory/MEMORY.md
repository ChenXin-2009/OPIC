## OPIC 项目
- 全称：Open Integrated Cosmos（开放集成宇宙）
- 基于 Web 的多尺度宇宙可视化与天文数据集成系统
- 技术栈：Next.js 16 + React 19 + Three.js r170 + Cesium 1.139 + Zustand 5
- 核心模块：轨道计算（NASA JPL DE440 + VSOP87）、卫星追踪（SGP4）、宇宙多尺度渲染（9层）、MOD插件系统
- 已部署在 Vercel，开源在 GitHub
- 正在进行软件著作权登记

## 核心定位修正（重要）
- **OPIC 的优势不是比 NASA/Google 的天文精度更高**（那不可能），而是：**开源 + Web + 可扩展（MOD架构） + 面向中国教育场景**
- NASA Eyes / Google 100,000 Stars / WorldWide Telescope 等产品要么封闭、要么停更、要么被墙、要么没有中文教育场景——OPIC 打的是 **可及性战和生态战**
- 一句话总结：**"OPIC 不是一个宇宙模拟器，而是一个开源的、可扩展的宇宙可视化平台——让任何人都能在此基础上构建自己的天文和教育应用"**
